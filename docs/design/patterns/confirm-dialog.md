# 확인창 (ConfirmDialog)

이 문서는 되돌리기 어렵거나 결과가 큰 행동 전에 띄우는 확인창의 모양과 문구 기준입니다. 브라우저 기본 `window.confirm`, `alert`, `prompt`는 새로 쓰지 않고 이 확인창을 씁니다.

## 언제 쓰나요

| 종류 | 쓰는 곳 | 확인 버튼 |
| --- | --- | --- |
| 위험 확인 (`tone="danger"`) | 계좌 삭제, 회원 탈퇴. 이후 선물 삭제, 위시리스트 초기화 | 빨간 채움 버튼 |
| 일반 확인 (`tone="default"`) | 되돌릴 수 있는 행동. 이후 메시지 숨기기 | 검은 채움 버튼 (`admin`) |

토스트로 충분한 결과 알림이나 되돌리기가 쉬운 행동에는 확인창을 띄우지 않습니다.

## 구성

- 컴포넌트: `components/ui/confirm-dialog.tsx`, Radix `AlertDialog` 기반입니다.
- 제목: 확인 문구의 첫 질문 문장입니다. 예: `계좌 정보를 삭제할까요?`, `정말 탈퇴할까요?`
- 설명: 질문 뒤에 오는 나머지 문장입니다. 무엇이 지워지는지, 되돌릴 수 있는지를 씁니다.
- 버튼 두 개: 왼쪽 `취소`(`admin-outline`), 오른쪽 확인 버튼입니다. 닫기(X) 버튼은 두지 않습니다.
- 확인 버튼 문구는 행동 이름으로 씁니다. `확인`, `예`는 쓰지 않습니다. 예: `삭제`, `탈퇴`.

## 모양

- 배경: `fixed inset-0 z-40 bg-black/45 backdrop-blur-[2px]` (관리자 안내와 같습니다)
- 상자: `w-[calc(100%-32px)] max-w-[400px] rounded-md border-2 border-ink bg-paper p-5 shadow-[5px_5px_0_var(--ink-deep)] sm:p-6`
- 제목: `text-lg font-black break-keep text-ink`
- 설명: `mt-2 text-sm font-medium leading-6 break-keep text-zinc-600`
- 버튼 줄: `mt-5 flex gap-2 sm:justify-end`. 모바일에서는 두 버튼이 `flex-1 h-11`로 반씩 차지하고, `sm` 이상에서는 내용 너비 `h-9`입니다.
- 위험 확인 버튼: Button 변형 `danger-solid`를 새로 둡니다. `h-9 rounded-md border border-danger bg-danger px-3.5 text-sm font-semibold whitespace-normal text-white transition-colors hover:bg-[#991b1b]`

## 동작

- 열리면 포커스는 `취소`에 갑니다. 위험한 버튼에 기본 포커스를 두지 않습니다.
- `Esc`는 취소와 같습니다. 바깥을 눌러도 닫히지 않습니다(AlertDialog 기본).
- 확인을 누르면 폼을 제출하고, 응답이 올 때까지 창을 열어 둔 채 두 버튼을 잠급니다. 확인 버튼 문구는 `삭제하는 중…`, `탈퇴하는 중…`으로 바뀝니다.
- 닫히면 포커스는 창을 연 버튼으로 돌아갑니다.

## 문구 위치

문구는 [copy.ts](../../../src/lib/design/copy.ts)에 둡니다. 기존 확인 문구를 제목과 설명으로 나누기만 하고 내용은 바꾸지 않습니다.

| 화면 | 제목 | 설명 | 확인 | 진행 중 |
| --- | --- | --- | --- | --- |
| 계좌 삭제 | 계좌 정보를 삭제할까요? | 은행, 예금주, 계좌번호가 모두 지워지고 되돌릴 수 없어요. 공개 위시리스트에도 계좌가 보이지 않아요. | 삭제 | 삭제하는 중… |
| 회원 탈퇴 | 정말 탈퇴할까요? | 계정, 위시리스트, 선물, 받은 메시지, 모인 금액 기록, 계좌 정보가 바로 모두 삭제되고 되돌릴 수 없어요. 탈퇴한 뒤에는 다른 사람이 같은 공개 주소를 쓸 수 있어서, 예전에 공유한 링크가 다른 사람의 위시리스트로 열릴 수 있어요. | 탈퇴 | 탈퇴하는 중… |

## 아직 브라우저 확인창을 쓰는 곳

선물 삭제, 메시지 숨기기, 위시리스트 초기화, 온보딩 만 14세 미만 확인은 #39 머지 뒤 다음 브랜치에서 바꿉니다. 온보딩 문구는 브라우저 버튼 이름(`확인`, `취소`)을 말하고 있어서 바꿀 때 문구도 함께 고칩니다.
